# MakeCountryLite と機能パック

[← README に戻る](../README.md)

MakeCountry には、すべての機能が入った **MakeCountry (フル版)** のほかに、
建国に必要なものだけを入れた **MakeCountryLite** と、Lite に機能を足す **機能パック** があります。
Lite にすべての機能パックを入れると、フル版と同じ遊び方になります。

「建国だけ遊びたい」「料理は要らない」など、サーバーに合わせて必要な機能だけを選べます。

## パックの一覧

| パック | 入っている機能 |
| --- | --- |
| **MakeCountryLite** (必須) | 国・土地・ロール・プロット・外交・戦争・税金・国庫・お金と送金・ホーム/TPA・チャット・メニュー・管理者機能・ショップ/マーケット/取引・スマートフォン |
| 職業パック | 職業・職業レベル・報酬・ランキング |
| 料理パック | 料理・調理器具・食材・作物 |
| 生産パック | 鍛冶・化学・鉱物・バイオーム・梱包・圧縮ブロック |
| 釣りパック | 釣り・魚・魚図鑑 |
| 装飾パック | 家具・和服・スーツ・日本刀・ネオンライト |
| 生活パック | 結婚・懸賞金・二つ名・バックパック |

- 料理人・鍛冶職人・化学者の **報酬 (お金と経験値)** は職業パックが払います。料理パックや生産パックだけを入れた場合、料理や鍛冶はできますが報酬は出ません
- 料理・鍛冶のレシピのレベル制限や品質には、職業パックの職業レベルが使われます (職業パックが無いときはレベル 1 として扱います)

## 導入

1. [Releases](https://github.com/karonyt/MakeCountry/releases) から次のどちらかをダウンロードします
   - `MakeCountryLite-vX.Y.Z.mcaddon` … Lite とリソースパック
   - `MakeCountryLite-AllPacks-vX.Y.Z.mcaddon` … Lite・すべての機能パック・リソースパック
2. 使いたい機能パックの `MakeCountry-<名前>-vX.Y.Z.mcpack` もダウンロードして開きます
3. ワールドの設定で **MakeCountryLite** と使う機能パックを追加します (リソースパックは自動で追加されます)
4. ワールド設定の「実験」で **ベータ API** をオンにします

- **MakeCountry (フル版) と MakeCountryLite・機能パックは、一緒に入れないでください。**
  一緒に入れると同じ機能が二重に動きます (チャットに警告が出ます)
- 機能パックだけを入れても動きません。必ず MakeCountryLite と一緒に入れてください
- 機能パックは後から追加・削除できます。削除しても、その機能のデータはワールドに残ります
- 設定ファイル (`scripts/config/`) は、それを使うパックごとに入っています。同じ名前のファイルはすべてのパックで同じ内容にしてください ([設定の変更](admin.md#設定の変更))

## フル版からの乗り換え

フル版を使っているワールドは、フル版を外して MakeCountryLite と機能パックを入れるだけで乗り換えられます。

- 国・土地・お金などのデータは、そのまま MakeCountryLite で使われます
- 職業レベル・魚の記録・結婚・懸賞金・二つ名などは、機能パックを入れたときに自動で引き継がれます
  - ワールドのデータ (魚の記録・懸賞金など) はワールドを開いたときに、プレイヤーのデータ (職業レベル・二つ名など) はそのプレイヤーがログインしたときに引き継がれます
  - バックパックの中身と梱包アイテムは、そのアイテムがプレイヤーのインベントリに入ったときに引き継がれます
- 引き継ぎのあとも、フル版のデータは消さずに残しています。フル版に戻すこともできます
  (ただし、乗り換えたあとに増えた職業レベルなど、機能パック側で変わったデータはフル版には戻りません)

## しくみ (詳しく知りたい人向け)

パック同士は `scriptevent` でやり取りしています。

- お金・土地・国のデータは MakeCountryLite が持ち、機能パックはお金の支払いや権限の確認を Lite に頼みます
- 職業レベル・報酬ブースト・国家ランクなど、ほかのパックがその場で使う値はスコアボードにも書き出しています
  (`mcjob_<職業>`・`mcjob_buff`・`mc_country_lv`・`mc_money_view`・`mc_days_view`。読み取り専用で、書き換えても反映されません)
- 報酬の支払いには ID を付けていて、通信が途切れて送り直しても二重には払われません
