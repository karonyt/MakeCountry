# MakeCountry

**統合版で建国鯖を作りたい**、そう思ってませんか？
そんなあなたにぴったりのアドオンが MakeCountry です。

Java 版の建国プラグインをモデルにした、建国・外交・戦争・経済・職業・生産の要素をまとめたアドオンです。
大規模建国サーバー「かろEarth」で使われている機能を、通常のワールドでも遊べるようにしています。

## 導入方法 (サーバー管理者向け)

1. [Releases](https://github.com/karonyt/MakeCountry/releases) から最新の `MakeCountry-vX.Y.Z.mcaddon` をダウンロードして開く
   (ビヘイビアパックとリソースパックの両方が入っています)
2. ワールドの設定でビヘイビアパック「MakeCountryBehavior」を追加する (リソースパックは自動で追加されます)
3. ワールド設定の「実験」で **ベータ API** をオンにする
4. ワールドに入り、チャットで `/setup` を実行する

これだけで建国鯖を始められます。

- 対応バージョン: Minecraft 統合版 1.26.60 以降
- 細かい仕様は [wiki](https://github.com/karonyt/MakeCountry/wiki) にまとめています

## 主な機能

- **建国と土地**: チャンク単位の領土、ロールごとの細かい権限、区画 (プロット) の貸し出し
- **外交と戦争**: 同盟・友好・敵対・連邦・併合、時間帯を決めた侵略戦争、懸賞金
- **経済**: 通貨・税金・国庫・維持費、ショップ・チェストショップ・プレイヤーマーケット
- **職業と生産**: 15 種類の職業、料理・鍛冶・化学のミニゲームと品質ランク、追加の鉱石・作物・バイオーム・家具・衣装
- **便利機能**: メニュー、スマートフォン、ホーム・TPA、各種チャット、結婚、二つ名、バックパック
- **多言語対応**: 日本語・英語・韓国語・中国語 (簡体字・繁体字)
